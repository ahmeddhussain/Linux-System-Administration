12. Lessons and traps

The things that cost time once and should never cost time again. Most of them are good interview material, because they show real troubleshooting.

12.1 Linux and services

TrapWhat to do
sshd keeps the first value of a keyword; drop-ins are read in name orderOur drop-in is 01-; check with sshd -T, not by reading files (INC-007)
systemd "started" is not "ready" (D-Bus services)Wait for the service's own readiness check (INC-003)
Runtime firewall changes vanish on reloadAlways permanent configuration, as whole files (D-038, D-052)
XFS cannot enable quotas with a remountMount options at mount time; unmount and mount if needed
NFSv4 clients do not show POSIX ACLsCheck ACLs on util01, not on the workstation
Copying /etc/skel/. copies its 0755 mode onto the homeCopy the contents of /etc/skel instead
rsyslog drops messages it cannot write; the sender has already handed them overKeep the volume from filling (space guard)
tar exits 1 when a file changes while being readThat is a warning; 2 is a failure
A partial or killed dnf update can break the system (crypto-policies ahead of SSH)Never interrupt dnf; patch with enough memory (D-037)
An EBS root volume cannot shrinkReplace the host (terraform -replace); data lives on util01 anyway
glibc nss-myhostname answers a host's own name locallyA host resolving itself proves nothing about DNS (DRILL-001)

12.2 FreeIPA and SSSD

TrapWhat to do
The AWS inventory variable state collides with the IPA roles' statePass state: present as a role parameter
Enrollment needs full server names; IPA's web server redirects short onesUse the FQDN (idm01.ahmed.internal)
A failed enrollment leaves an empty /etc/ipa/ca.crt that breaks every retryRemove it if it is empty and the host is not enrolled
IPA refuses a one-time password for a host it still lists as enrolledRelease (disable) the old entry before re-enrolling a rebuilt host
SSSD caches "no sudo rules" from before they existedReset the cache when the identity data changes (checksum)
SSSD can stay offline for minutes after an outageRestart an offline SSSD on every run
A reinstalled IPA gives users new numbers; files are stored by numberFixed IDs (D-060); backups by name
OpenSCAP reads /etc/passwd, not SSSDIPA-owned files look "unowned"; documented exception

12.3 Ansible, SSH and shells

TrapWhat to do
ssh in a script reads the script's stdinUse ssh -n or < /dev/null
pgrep -f or grep match their own command lineUse [x]yz patterns. Ansible also logs every command line it runs into /var/log/messages, so search a log by its program field, not for a word
With pipelining, a running module shows as a bare python3Look at ps --forest under the ansible user's sshd session
Secrets printed by ad-hoc Ansible end up in logsNever pipe or print a secret through Ansible ad hoc
Long SSH sessions through Instance Connect can stallRun long jobs detached and poll (run_on_control01)
Unquoted YAML values containing ": " become mappingsQuote shell commands that contain a colon and a space
Multi-line Jinja in set_fact keeps whitespaceUse {%- -%}
Central log directories are named by FQDN/srv/logs/ws-ops01.ahmed.internal/, not /srv/logs/ws-ops01/

12.4 Terraform and AWS

TrapWhat to do
AWS-managed interfaces can take a "fixed" IPExplicit subnet CIDR reservation (INC-006)
Deleting a security group hangs while instances still use itCreate the new group and rules, move the instances, delete the old one last
Interrupting an apply can leave resources AWS created but state never recordedLet applies finish; find orphans by tag (Project=ahmed-infra)
Security group egress also applies to forwarded packetsgw01 needs explicit forwarding egress rules (D-024)
Long-lived admin access keys get leakedMFA, one key, least privilege, rotation (INC-005)
Not all instance types are allowed on the AWS Free planc7i-flex.large for the 4 GB host (D-025)
